# 系统增强功能快速使用指南

## 🚀 快速开始

系统已成功升级！以下是新功能的快速使用说明。

---

## 📱 教师端新功能

### 1. 查看直播状态栏

**位置**：页面顶部自动显示

当有课堂正在直播时，顶部会自动显示一个**紫色渐变**的状态栏：

```
🔴 2个课堂正在直播
┌────────────────────────────────────┐
│ 📹 刘教授 正在讲课                 │
│ 高等数学 · 👤 25人 · ⏱️ 15分钟      │  [➡️]
└────────────────────────────────────┘
```

- 点击任意课堂卡片即可进入直播教室
- 可点击右上角 ✕ 临时关闭状态栏

### 2. 查看消息已读状态

**位置**：消息气泡右下角

在发送消息后，可以看到：
```
✓✓ 12/25已读  ← 点击查看详情
```

点击后弹窗显示：
- **已读标签页**：显示所有已读学生和阅读时间
- **未读标签页**：显示未读学生名单

**用途**：
- ✅ 快速点名
- ✅ 确认重要通知的送达情况
- ✅ 了解学生活跃度

### 3. 置顶重要公告

**操作**：长按消息 → 选择"置顶"

置顶后的消息会：
- 固定在聊天窗口顶部
- 显示 📌 图标
- 支持多条置顶（按顺序排列）

**适用场景**：
- 课程通知
- 作业要求
- 考试安排

### 4. 使用快捷指令

**位置**：直播课堂工具栏

点击 ⚡ 快捷指令按钮，选择：

#### 📋 /call - 发起签到
```
1. 设置签到标题（如："第3周签到"）
2. 选择签到时长（3/5/10/15分钟）
3. 点击"发起签到"
```

学生端会弹出签到窗口，倒计时结束后自动统计。

#### 📝 /quiz - 随堂测试
```
1. 输入测试问题
2. 添加选项（至少2个，最多6个）
3. 标记正确答案
4. 设置答题时长
5. 点击"发起测试"
```

学生端会显示测试界面，系统自动判分。

### 5. 查看举手列表

**位置**：直播课堂工具栏

点击 🔔 举手列表按钮（有徽章提示待处理数量）

列表显示：
- 学生姓名和头像
- 等待时间（高亮显示）
- 问题描述（如果学生填写了）

点击"已处理"按钮标记处理完成。

### 6. 创建对话分组

**位置**：消息中心侧边栏

系统已自动创建3个默认分组：
- 📚 正在上课
- ✏️ 未读作业
- 👥 班级群

**自定义分组**：
```
1. 点击"+"创建新分组
2. 输入名称，选择图标和颜色
3. 将对话拖入分组
```

## 🎓 学生端新功能

### 1. 查看直播提醒

**自动显示**：当老师开启直播时

页面顶部会显示：
```
🔴 刘教授 正在讲课
高等数学 · 👤 25人在教室 · ⏱️ 已进行15分钟

[点击进入] ➡️
```

### 2. 举手提问

**位置**：直播课堂下方

点击 ✋ "举手提问"按钮：
```
1. 可选填写问题描述
2. 点击"确认举手"
3. 等待老师回应（按钮变灰，显示"等待老师回应..."）
```

老师处理后，按钮恢复可用。

### 3. 消息表情回复

**操作**：长按消息 → 选择表情

支持的表情：
👍 ❤️ 😂 😮 😢 🙏 👏 🔥

- 点击已添加的表情可取消
- 可以看到每个表情的点赞人数
- 点击表情可查看点赞用户列表

### 4. 参与快捷指令

#### 签到
当老师发起签到时，自动弹窗：
```
课堂签到
────────
剩余时间：4分58秒

[点击签到]
```

#### 测试
当老师发起测试时，显示答题界面：
```
问题：1 + 1 = ?
○ A. 1
○ B. 2  ← 选择
○ C. 3
○ D. 4

剩余时间：55秒
[提交答案]
```

### 学生端

1. **及时回应**
   - 看到消息后及时标记已读

2. **主动参与**
   - 有疑问及时举手
   - 积极参与测试和签到

3. **查找资料**
   - 使用附件筛选功能快速找到课件
   - 按类型筛选：图片、文档、链接

## 🔧 常见问题

### Q: 直播状态栏不显示？
**A**: 检查：
1. 是否有课堂正在直播（status='active'）
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面

### Q: 举手后没有反应？
**A**: 
1. 确认课堂正在进行中
2. 等待老师查看举手列表
3. 如需取消，刷新页面

### Q: 看不到消息已读状态？
**A**: 
1. 只有发送者可以查看
2. 需要对话中有其他成员
3. 群聊消息才显示已读统计

### Q: 快捷指令失败？
**A**: 
1. 确认有教师权限
2. 确认课堂正在直播
3. 检查网络连接
