## 🔧 后端API测试

### 文件上传
```bash
POST /api/v1/chat/upload
- 上传图片成功
- 上传文件成功
- 返回url、filename、size
```

### 离开对话
```bash
POST /api/v1/chat/conversations/:id/leave
- 标记left_at时间
- 群聊发送系统消息
- 返回成功提示
```

### 消息编辑
```bash
PUT /api/v1/chat/messages/:id
- 只能编辑自己的文本消息
- 标记is_edited和edited_at
- 返回成功
```

### 消息删除
```bash
DELETE /api/v1/chat/messages/:id
- 只能删除自己的消息
- 标记is_deleted
- 内容改为"[消息已删除]"
```
