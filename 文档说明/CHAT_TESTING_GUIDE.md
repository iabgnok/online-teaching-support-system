## 常见问题排查

### 问题1：未读徽章不显示
- 检查：API `/chat/conversations` 是否返回unread_count
- 检查：浏览器Console是否有错误
- 解决：刷新页面，检查后端日志

### 问题2：消息发送失败
- 检查：WebSocket是否连接（Console查看"Socket connected"）
- 检查：后端是否运行（http://localhost:5000）
- 检查：Network标签是否有502错误
- 解决：重启后端服务

### 问题3：实时消息不更新
- 检查：Socket连接状态
- 检查：后端SocketIO事件是否触发
- 解决：检查后端日志，查看事件处理

### 问题4：对话列表为空
- 检查：数据库是否有测试数据
- 运行：`python check_chat_data.py` 验证数据
- 解决：重新运行数据创建脚本

## API测试

### 获取对话列表
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:5000/api/v1/chat/conversations
```

### 获取消息
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:5000/api/v1/chat/conversations/1/messages
```

### 发送消息
```bash
curl -X POST -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content":"测试消息","message_type":"text"}' \
  http://localhost:5000/api/v1/chat/conversations/1/messages
```
