# 课堂讨论区UI统一修复报告

## 修复日期
2026年2月4日

## 问题描述

用户反馈了两个UI问题：

1. **收起按钮位置问题**：收起按钮没有靠到边缘，还有很大的空位
2. **组件UI不统一**：课堂讨论区的输入框等消息窗口内部的组件UI没有与外部聊天窗口设计统一

## 解决方案

### 1. 收起按钮位置修复

**问题分析**：
- 原CSS使用 `right: 0` 导致按钮与边缘有间隙

**修复方案**：
```css
.collapse-toggle-wrapper {
  position: absolute;
  right: -1px;  /* 改为 -1px，让按钮真正靠到边缘 */
  top: 50%;
  transform: translateY(-50%);
  z-index: 100;
}
```

### 2. 组件UI统一改造

#### 2.1 使用MessageInput组件替换自定义输入框

**改造前**：
- 使用自定义的textarea和发送按钮
- 缺少附件上传、表情选择等功能
- 样式与外部聊天不一致

**改造后**：
```vue
<MessageInput 
  ref="messageInputRef"
  :conversation-id="currentConversationId"
  :conversation-subtype="activeChat === 'discussion' ? 'live_class_discussion' : 'normal'"
  :reply-to="replyToMessage"
  :editing-message="editingMessage"
  @send="handleSendMessageFromInput"
  @cancel-reply="replyToMessage = null"
  @cancel-edit="editingMessage = null"
  @typing="handleTyping"
/>
```

**优势**：
- ✅ 完整的Telegram风格输入体验
- ✅ 支持附件上传（图片、视频、文件、语音）
- ✅ 支持表情选择器
- ✅ 支持回复和编辑消息
- ✅ 支持拖拽上传
- ✅ 与外部聊天UI完全一致

#### 2.3 更新JavaScript逻辑

**新增computed属性**：
```javascript
// 当前对话ID
const currentConversationId = computed(() => {
  return activeChat.value === 'discussion' 
    ? props.discussionConversationId 
    : props.classGroupConversationId;
});
```

**新增状态管理**：
```javascript
const replyToMessage = ref(null);
const editingMessage = ref(null);
const messageInputRef = ref(null);
```

**新增事件处理方法**：
```javascript
// 从MessageInput组件接收消息
const handleSendMessageFromInput = (content) => {
  const conversationId = currentConversationId.value;
  
  emit('send-message', {
    conversationId,
    message: content,
    chatType: activeChat.value,
    replyTo: replyToMessage.value?.id,
    editingId: editingMessage.value?.id
  });
  
  // 清除回复和编辑状态
  replyToMessage.value = null;
  editingMessage.value = null;
};

// 取消回复
const handleCancelReply = () => {
  replyToMessage.value = null;
};

// 取消编辑
const handleCancelEdit = () => {
  editingMessage.value = null;
};
```

**移除废弃代码**：
- 移除 `newMessage` ref（由MessageInput内部管理）
- 移除 `showActionMenu` ref（改用直接按钮）
- 移除 `sendMessage` 方法（使用handleSendMessageFromInput）
- 移除 `handleShiftEnter` 方法（MessageInput内部处理）
- 移除 `toggleActionMenu` 方法（不再需要）
