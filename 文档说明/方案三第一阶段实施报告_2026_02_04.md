## 📝 技术细节

### CSS 变量系统

```css
/* 颜色变量 */
--primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
--primary-color: #667eea
--secondary-color: #764ba2

/* 消息背景 */
--message-bg-received: #f5f5f7
--message-bg-sent: var(--primary-gradient)

/* 文字颜色 */
--message-text-received: #333
--message-text-sent: #fff

/* 特殊消息 */
--system-message-bg: #e3f2fd
--system-message-text: #1976d2

/* 边框和分隔线 */
--border-color: #e5e5e5
--divider-color: #efefef

/* 阴影 */
--shadow-light: 0 1px 3px rgba(0, 0, 0, 0.05)
--shadow-medium: 0 2px 8px rgba(0, 0, 0, 0.1)

/* 气泡设计 */
--bubble-radius: 12px
--bubble-padding: 10px 14px
```

### 新增伪元素

时间分隔线现在使用 `::before` 和 `::after` 实现两侧竖线：

```css
.time-divider::before,
.time-divider::after {
  content: '';
  position: absolute;
  top: 50%;
  width: 40px;
  height: 1px;
  background: var(--divider-color);
}

.time-divider::before {
  left: 0;
}

.time-divider::after {
  right: 0;
}
```

## 📞 问题排查

### 若消息气泡颜色不对

**可能原因**: CSS 变量未生效  
**解决方案**:
1. 检查浏览器是否支持 CSS 变量
2. 清除浏览器缓存
3. 重新加载页面

### 若时间分隔线不显示

**可能原因**: 伪元素宽度为 0  
**解决方案**:
```css
.time-divider {
  display: flex;
  align-items: center;
  position: relative;
}
```

### 若按钮颜色不统一

**可能原因**: 没有更新所有选择器  
**解决方案**:
1. 搜索旧的颜色值（#409eff）
