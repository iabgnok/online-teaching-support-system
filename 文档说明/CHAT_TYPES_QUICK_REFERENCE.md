## 🔄 创建流程

### 一对一私聊
```
1. 点击"新建对话"
2. 选择"👤 私聊"
3. 搜索用户 → 选择1个
4. 创建 ✅
   └─> 检查是否已存在
```

### 普通群聊
```
1. 点击"新建对话"
2. 选择"💬 群聊"
3. 输入群组名称 *必填
4. 搜索用户 → 选择多个
5. 创建 ✅
```

### 班级群组
```
1. 点击"新建对话"
2. 选择"🏫 班级群组"
3. 选择班级 *必填
4. 创建 ✅
   ├─> 自动添加所有学生 (member)
   ├─> 自动添加所有教师 (admin)
   ├─> 自动命名: "{班级名} - 班级群"
   └─> 检查该班级是否已有群组
```

### 课程群组
```
1. 点击"新建对话"
2. 选择"📚 课程群组"
3. 选择课程班级 *必填
4. 创建 ✅
   ├─> 只添加教师 (admin)
   ├─> 自动命名: "{班级名} - 课程群"
   └─> 检查该班级是否已有群组
```

## 📋 成员角色

```
owner (群主)
  ├─ 创建对话的用户
  ├─ 拥有最高权限
  └─ 可管理所有成员

admin (管理员)
  ├─ 班级群组: 所有教师
  ├─ 课程群组: 所有教师
  └─ 可管理普通成员

member (普通成员)
  ├─ 班级群组: 所有学生
  ├─ 普通群聊: 所有成员
  └─ 只能发送消息
```

## 🚀 快速命令

### 创建私聊 API
```bash
POST /api/v1/chat/conversations
{
  "type": "private",
  "member_ids": [123]
}
```

### 创建普通群聊 API
```bash
POST /api/v1/chat/conversations
{
  "type": "group",
  "title": "学习小组",
  "member_ids": [123, 456, 789]
}
```

### 创建班级群组 API
```bash
POST /api/v1/chat/conversations
{
  "type": "class_group",
  "class_id": 1001
}
# 自动添加班级所有成员
```

### 创建课程群组 API
```bash
POST /api/v1/chat/conversations
{
  "type": "course_group",
  "class_id": 1001
}
# 只添加教师
```

## 🎯 使用建议

### 何时使用一对一私聊？
- ✅ 学生向老师提问
- ✅ 私密讨论
- ✅ 一对一辅导

### 何时使用普通群聊？
- ✅ 兴趣小组讨论
- ✅ 项目小组
- ✅ 自由组织的群组

### 何时使用班级群组？
- ✅ 班级通知发布
- ✅ 作业讨论
- ✅ 班级活动组织
- ✅ 全班需要参与的讨论

### 何时使用课程群组？
- ✅ 教师备课讨论
- ✅ 教学方案研究
- ✅ 教研组会议
- ✅ 教师之间协作

## ⚠️ 注意事项

### 唯一性
- 同一对用户只能有1个私聊
- 同一班级只能有1个班级群组
- 同一班级只能有1个课程群组
- 普通群聊无限制

### 权限
- 班级/课程群组需要是该班级成员才能创建
- 系统自动验证权限

### 成员管理
- 班级/课程群组成员由系统管理，不可手动删除
- 私聊不能添加成员
- 普通群聊可自由管理成员
