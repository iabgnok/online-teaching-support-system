# 线上授课聊天窗口升级方案

## 📋 现状分析

### 当前实现
- ✅ 基础文本消息
- ✅ 系统消息（用户加入/离开）
- ✅ 考勤打卡功能
- ✅ 课堂任务发布
- ✅ 举手功能（学生端）
- ✅ 快捷表情（学生端）
- ✅ 消息撤回

### 存在的问题
1. **视觉层次不清晰** - 消息气泡缺乏明显的视觉区分
2. **交互体验一般** - 缺少"正在输入"、消息状态等实时反馈
3. **功能入口隐藏** - 考勤、任务等功能入口不够直观
4. **滚动体验差** - 缺少"滚动到底部"、"新消息提示"
5. **消息密度高** - 缺少时间分组，视觉疲劳

## 🎨 UI设计方案

### 消息气泡设计

```
自己的消息（教师/学生）:
┌─────────────────────────┐
│  我的消息内容           │ ← 蓝色渐变背景
│  14:30 ✓✓              │ ← 已读状态
└─────────────────────────┘
              ↑ 尾巴在右下

对方消息:
┌─────────────────────────┐
│ 👤 张三                 │ ← 头像+姓名
│  对方消息内容           │ ← 白色背景
│  14:30                  │
└─────────────────────────┘
↑ 尾巴在左下
```

### 特殊消息卡片设计

**考勤卡片**:
```
┌───────────────────────────────┐
│ 📅 课前签到                   │
│ ──────────────────────────    │ ← 进度条
│ ✅ 25/30 人已签到 (83%)       │
│ ⏰ 剩余时间: 03:45            │
│                               │
│ 👥 已签到: 张三、李四...       │
│ [立即签到] (学生端)           │
│ [查看详情] (教师端)           │
└───────────────────────────────┘
```

**任务卡片**:
```
┌───────────────────────────────┐

│                               │
│ [标记完成] (学生端)           │
│ [查看完成情况] (教师端)        │

```

## 💡 与IM系统的集成方案

### 选项A：独立保持（推荐）
- 课堂聊天保持独立，专注教学场景
- 使用现有的 `ChatMessage` 表
- 保留考勤、任务等特殊功能

### 选项B：部分集成
- 课堂聊天使用独立表
- 私下交流引导到IM系统
- 添加"课后继续讨论"按钮

### 选项C：完全集成
- 课堂创建时自动创建对应的 `Conversation`
- 所有消息存入 `IMMessage`
- 扩展 `message_type` 支持考勤、任务

**建议**: 采用**选项A**，因为：
- 课堂聊天有特殊需求（考勤、任务、举手等）
- 课堂结束后消息归档需求不同
- 减少复杂度，保持系统清晰
