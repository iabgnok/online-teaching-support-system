# 在线授课功能严重Bug修复报告
**修复日期**: 2026年2月4日

## 🐛 问题描述

教师开始授课后，出现两个严重问题：
1. 学生收不到课堂开始的通知
2. 学生显示"无法进入课堂"（403 Forbidden）
3. 学生进入课堂后显示空白页面

## 🔍 问题根源分析

### 问题1：学生无法看到活跃课堂（最严重）

**位置**: `api/v1/chat.py` - `/chat/live_status` 端点（第3687行）

**错误代码**:
```python
# ❌ 错误：使用了 user_id 而不是 student_id
student_classes = StudentClass.query.filter_by(student_id=user_id).all()
```

**问题说明**:
- `StudentClass` 表的 `student_id` 字段引用的是 `Student.student_id`
- 但代码使用了 `Users.user_id`，导致查询结果为空
- 结果：学生看不到任何活跃课堂

**测试结果**:
```
错误逻辑（使用 user_id）：找到 0 个班级
正确逻辑（使用 student_id）：找到 2 个班级（包括正在授课的班级205）
```

### 问题2：路由配置错误

**位置**: `frontend/src/components/MessageList.vue`（第392行）

**错误代码**:
```javascript
// ❌ 错误路由
router.push(`/student/live-class/${lessonId}`)
```

**问题说明**:
- 路由配置中只有 `/live-class/:lessonId`
- 但代码尝试导航到 `/student/live-class/:lessonId`
- 结果：Vue Router 找不到匹配的路由，显示空白页面

## ✅ 修复方案

### 修复1：正确使用 student_id 查询

**文件**: `api/v1/chat.py`

```python
# ✅ 修复后
elif role == 'student':
    # 学生看到自己所在班级的直播（status='active'）
    # 1. 找出学生所在的 Class ID
    student_profile = g.user.student_profile
    if student_profile:
        student_classes = StudentClass.query.filter_by(student_id=student_profile.student_id).all()
        class_ids = [sc.class_id for sc in student_classes]
        
        if class_ids:
            lives = LiveClass.query.filter(
                LiveClass.class_id.in_(class_ids),
                LiveClass.status == 'active'
            ).all()
            for live in lives:
                active_lives.append(live)
```

**关键改动**:
- 添加 `student_profile = g.user.student_profile` 检查
- 使用 `student_profile.student_id` 而不是 `user_id`

### 修复2：修正学生端路由

**文件**: `frontend/src/components/MessageList.vue`

```javascript
// ✅ 修复后
const userRole = localStorage.getItem('user_role')
if (userRole === 'teacher') {
  router.push(`/teacher/live-class/${lessonId}`)
} else {
  router.push(`/live-class/${lessonId}`)  // 移除 /student 前缀
}
```

## 📝 额外说明

### 关于权限验证
权限验证逻辑 `check_class_permission()` 是**正确的**：
- 它正确使用 `student.student_id` 来检查学生是否在班级中
- 403 错误是因为测试时使用了不在课堂班级中的学生账号

### 数据库结构
```
Users.user_id (用户ID) → Student.user_id (关联)
                      ↓
                  Student.student_id (学生ID)
                      ↓
                  StudentClass.student_id (外键)
```

**关键点**: 
- `StudentClass.student_id` 引用 `Student.student_id`
- **不是** `Users.user_id`
