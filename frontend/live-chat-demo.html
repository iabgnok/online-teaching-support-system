🎓 直播聊天模块改进演示

展示使用聊天组件和独立切换按钮的直播聊天功能

📱 聊天切换按钮组件

<ChatSwitchButton
  tab-type="discussion"
  :label="'课堂讨论'"
  :unread-count="5"
  :is-active="activeTab === 'discussion'"
  @switch="activeTab = $event"
/>

💬 直播聊天面板组件

<LiveClassChatPanel
  :discussion-conversation-id="discussionId"
  :class-group-conversation-id="classGroupId"
  :role="'student'"
  :online-count="25"
  @switch-tab="handleTabSwitch"
  @send-message="handleSendMessage"
/>

✨ 主要改进特性

  • 组件化设计 - 使用统一的聊天组件，提高代码复用性
  • 独立切换按钮 - 专门设计的切换按钮组件，支持未读消息显示
  • 直播模式优化 - ChatWindow组件支持直播场景的特殊需求
  • 响应式设计 - 适配不同屏幕尺寸的显示效果
  • 实时状态显示 - 在线人数和状态指示器
  • 多角色支持 - 支持教师和学生不同的功能权限
  • 消息功能完整 - 支持回复、编辑、删除、反应等完整功能
  • 折叠控制 - 可折叠的聊天面板，节省屏幕空间

📖 使用说明

1. 导入组件

import LiveClassChatPanel from '@/components/live-class/LiveClassChatPanel.vue'
import ChatSwitchButton from '@/components/live-class/ChatSwitchButton.vue'

2. 在模板中使用

<LiveClassChatPanel
  :discussion-conversation-id="discussionId"
  :class-group-conversation-id="classGroupId"
  :role="userRole"
  :online-count="onlineCount"
  @switch-tab="handleTabSwitch"
  @send-message="handleSendMessage"
/>

3. 必需的Props

  • discussion-conversation-id - 课堂讨论对话ID
  • role - 用户角色 ('teacher' | 'student')
  • messages - 消息数组

4. 可选的Props

  • class-group-conversation-id - 班级群对话ID
  • online-count - 在线人数
  • is-collapsed - 是否折叠
  • discussion-unread - 讨论未读数
  • class-group-unread - 班级群未读数
